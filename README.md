# 🌟 Pluxy Super-App

An all-in-one next-generation social, entertainment, and creator monetization ecosystem built with modern web technologies, Web Audio, PWA capabilities, and interactive AR lenses.

![Pluxy Banner](assets/icons/icon-512.png)

## ✨ Features

### 🎬 Reels Studio & Creator Monetization
- **Full-Featured Reels Creator**: 15-second recording, 8 real-time visual CSS filters, and 10 built-in trending tracks powered by the Web Audio API.
- **💰 Creator Studio**:
  - Live analytics (Views, RPM rate, Lifetime Earnings).
  - Instant UPI Payouts with simulated instant settlement and digital receipts (`PLX...`).
  - Creator tipping and virtual gifts during live streams and reels.

### 📸 Camera & 32+ Snapchat AR Lenses
- Real-time video camera feed with multi-tier camera constraints (front/rear).
- 4 categorized filter tabs:
  - 🐾 **Animals**: Puppy, Cute Cat, Bunny, Panda, Royal Lion
  - ✨ **Glamour**: Princess Crown, Love Blush, Golden Hour, Sakura, Butterfly, Ice Queen, Fairy, Angel
  - 🕶️ **Cyber**: Cyber Shades, Matrix, Neon Devil, Fire Aura, Rainbow, Lightning, Kitsune Mask, Galaxy, Glitch, Steampunk
  - 🎭 **Memes/Fun**: Thug Life 8-bit, Retro VHS, Bubblegum, Cash Rain, Top Hat, Party Confetti, Vampire, Disco Neon, Superstar

### 💬 Social & Messaging
- Stories with 24-hour expiration, reaction meters, and reply threads.
- Direct messaging with voice notes, media attachments, and typing indicators.
- Voice and video calling interface with end-to-end simulated signaling.
- Interactive SnapMap with real-time location pins and status updates.

- Dynamic content moderation and user role management.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/pluxy-superapp.git
cd pluxy-superapp
```

### 2. Run locally
You can run Pluxy using Python or any static HTTP server:
```bash
python server.py
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

Or simply double-click:
```cmd
Start-Pluxy-Live-Server.bat
```
